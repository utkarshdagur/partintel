How confidence is computed

1 · ExtractionEach source reports how clean and explicit its value was (0.55–0.95).
2 · Effectivesource authority × extraction confidence. Authority: PDF datasheet 0.95 · manufacturer web 0.85 · photo OCR 0.70.
3 · Mergebest effective confidence + 0.08 per additional agreeing source, capped at 0.98. A single source is discounted × 0.95 — with no second source there is no independent cross-check.
4 · Conflictan unresolved disagreement is fixed at 0.40 and never auto-published.
Routinga field is verified only if confidence ≥ 0.75, no conflict, and no validation error — otherwise it lands in the needs_review queue.
Heuristic weights, not calibrated probabilities — fine for a review queue, not for downstream ML training without re-weighting.
